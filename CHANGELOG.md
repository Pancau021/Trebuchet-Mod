# Changelog

All notable changes to **Trebuchet Mod** are documented in this file.

## \[1.0\] - 2026-11-02

### Added

-   Classic Mode and SpringBoard Mode.
-   SpringBoard-style home screen layout.
-   Widget page support in SpringBoard Mode.
-   Dock customization, including position adjustment.
-   Additional launcher appearance and layout options.

### Improved

-   General launcher usability.
-   Layout consistency between launcher modes.

### Notes

-   First public release of Trebuchet Mod.
-   Compatibility may vary depending on Android version, ROM, and
    device.
-   When reporting a bug, include the device model, Android version, ROM
    build, and steps to reproduce.
